# 各コンポーネントの責務
## コンポーネントの種類と責務

## 画面

### Purchase
- **責務**: 購入に関する画面を表示し、ユーザーが購入情報を入力・確認できるようにする。
- **主な機能**:
  - 購入情報の一覧表示
    - 購入日
    - 即日消費の合計金額
    - 計画消費の合計金額
    - 月次消費の合計金額
    - 仕入れ食数
  - 新規購入の追加
    - 購入日
    - 即日消費の合計金額
    - 計画消費の合計金額
    - 月次消費の合計金額
    - 仕入れ食数
  - 購入情報の編集
  - 購入情報の削除
  - 購入情報の詳細表示

## MealStock
- **責務**: 食材の在庫に関する画面を表示し、ユーザーが在庫情報を確認・管理できるようにする。
- **主な機能**:
  - 在庫情報の一覧表示
    - 現在の在庫食数
    - 1日の消費食数
    - 最終反映日
  - 新規在庫の追加
  - 在庫情報の編集
  - 在庫情報の削除
  - 在庫情報の詳細表示
