# Summary / Analysis API の実装状況

このファイルは、設計時に作成された Summary / Analysis の契約書を、現在の公開ルートに合わせて更新したものである。

現行のアプリケーションは次のルートだけを登録している。

- `/`（`GET`）
- `/purchases`
- `/meal-stock`

したがって、Summary と Analysis の API は現時点では**未実装・未公開**であり、成功時レスポンスの契約は存在しない。

| 設計時のパス | 現在の状態 |
| --- | --- |
| `GET /Summaries` | ルート未登録。アプリ固有の JSON レスポンスは定義されていない |
| `GET /analysis` | ルート未登録。アプリ固有の JSON レスポンスは定義されていない |

これらのパスへの通常のリクエストは、Hono の未一致ルートとして `404 Not Found` になる。以前の「10 日間」の集計値・分析値は実装から返されていないため、本契約書ではレスポンスモデルとして公開しない。
