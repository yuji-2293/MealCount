# Auth User API契約書

## エンドポイント

### GET /api/me
- 認証済みユーザー情報を取得する
- レスポンス:
  - 200: ユーザー情報
  - 401: Unauthorized

### POST /api/auth/* 
- 認証関連の処理を行う
- 例: サインイン、サインアップ
- レスポンス:
  - 200: 成功
  - 400: エラー

### middleware
- 認証済みユーザー情報を取得するためのミドルウェア
- レスポンス:
  - 401: Unauthorized // 認証情報がない場合
  - 200: 認証済みユーザー情報取得成功 // 認証情報があり、ユーザーIDが存在する場合
  - 403: Forbidden // ユーザーIDが存在しない場合
